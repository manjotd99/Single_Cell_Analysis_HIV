## Single-cell analysis of immune states in HIV-associated neurological disorders

This repository contains a small, curated sample of figures from a single-cell RNA-seq analysis of publicly available human data (GSE202410). The analysis focuses on immune cell states in cerebrospinal fluid (CSF) and blood, with emphasis on CD14 and CD16 monocyte populations relevant to neuroinflammation.

Single-cell RNA-seq data were analyzed in R using Seurat and tidyverse-based workflows within the RStudio environment. Core steps included quality control, normalization, dimensionality reduction, clustering, and gene-level visualization. Example figures highlight CLEC7A expression across immune cell states in HIV and control samples.

This repository is intended as a portfolio sample to demonstrate single-cell analysis, biological interpretation, and figure generation. Full analysis code and additional results are available upon request.
